# よこぼカート 生成コース連携版

20260502のよこぼカート3Dに、20260707サーキット生成パイプラインのコースを接続した版。
レシピJSON→ビルド→同期、でゲームの新コースが増える。

```
（サーキット生成パイプラインで）レシピを書いて build.ps1
→ このフォルダで .\sync-courses.ps1
→ ゲームのコース選択に自動で出てくる
```

## 遊び方

```powershell
python -m http.server 8128
# → http://localhost:8128/           マシンセレクトの「コース情報」で選択
# → http://localhost:8128/?course=kart_meadow   URLでも直接指定できる
```

## 現在のコース

| コース | 全長 | 世界 |
|---|---|---|
| ラボサーキット | 201m | 従来のラボ内装（フォールバック。コース未指定時） |
| kart_meadow | 199m | 草原・松林・花（生成GLB地形） |
| kart_canyon | 217m | 渓谷・岩場（生成GLB地形) |
| kart_city | 212m | 街中（商店街・ビル群・街路樹・街灯。20260705のアセットをprops機能で焼き込み） |

生成3コースのBGMは、Ace Step v1.5生成の `bgm15_kart_*_v1` をゲーム向けOGG
（mono / 22.05 kHz / 64 kbps）に軽量化したものを使用する。

生成3コースのGLBは、gltf-transform 4.3.0のMeshopt highで配信用に軽量化済み。
3ファイル合計は10.84 MiBから1.82 MiB（83.2%削減）。元GLBは
`../20260707_サーキット生成パイプライン/dist/kart_*.glb` に保存されている。
復元する場合は元GLBをこのフォルダの `courses/` へ同名コピーする。

## 選べるマシン

- ラボカート（従来モデル）
- ローポリバイク（20260705のBlender 3Dアセット生成パイプライン製）
- ローポリカート（20260705のBlender 3Dアセット生成パイプライン製）

1PとCPUは個別にマシンを選択できる。ローポリ2車種にもカラー選択が適用され、
キャラクターの搭乗位置は車種ごとに設定している。

## 仕組み（レベル1＋2実装済み）

- **レベル1**: `trackPoints`（ハードコード11点）を waypoints JSON（128点）読み込みに置換。
  道路メッシュ・CPU AI・コース外判定・順位計算は全部カーブ由来なので**無改修で追従**
- **レベル2**: コースGLB（地形＋縁石つき路面）を世界として敷き、ラボの床・壁・小道具を差し替え。
  ゲームの道路リボンがGLB路面の上に重なり、縁石・土の路肩がその両脇に見える構成。
  空・霧・環境光も屋外昼仕様に切替
- ゲーム側の `roadWidth` はコースの `track_width` を使う（判定とGLB路面が一致する）

## コースを追加するときの絶対条件

ゲームの物理は平面（y=0）前提。パイプライン側のレシピは必ず
**`height_wave: 0` と `banking_max_deg: 0`** でビルドすること（sync-courses.ps1のコメント参照）。

## デバッグフック

`window.__kart` に player / rival / state / samples / curve / startRace 等を公開。
自動テストと、レベル3（高低差・バンク対応）の作業用。

## レベル3への道（未着手）

高低差・バンクありコースを走らせるには:
1. カートのy座標とピッチ/ロールを接地に合わせる（three-mesh-bvh でレイキャスト。
   20260707のdemo/index.htmlに実装例あり）
2. `courseProgress` / `updateTrackState` は2D(x,z)距離なので高低差があってもほぼそのまま使える
3. カメラ追従・アイテム（ミサイル等）の高さ処理
4. waypointsのy値を使う（今は0に潰している）
